# QSO-026 Shipped — Test Ingestion

**Date:** 2026-08-15

## What shipped

`qsos ingest` parses JUnit XML and Jest JSON from `test-results/`, matches tests to Gherkin scenarios (three-pass: `@scenario` ref, name match), and adds `VERIFIES` edges to the graph registry.

`qsos query --coverage` reports verified / failing / untested per scenario.

## Commands

```bash
qsos ingest --root .
qsos query --coverage --root .
```

## Unblocks

Full graph-assisted paths in `/qsos-verify` and `/qsos-coverage-check` (Step 1c / 5b).
