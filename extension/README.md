# extension/

Future home of the QSOS VS Code extension — a lightweight side panel providing:

- Live skill inventory (all deployed QSOS skills with status)
- Utility run results (green/red per linter check)
- Ticket state at a glance (active, ready, blocked)
- Quick-launch buttons for common QSOS chain entry points

The extension is designed for optional installation. The full QSOS system functions without it — the extension adds visibility, not capability.

Nothing lives here yet. When extension work begins, a `package.json` with the VS Code extension manifest will be the entry point.
